# Dota 2 Overlay — Project Context

## Goal
Build a lightweight Dota 2 overlay with real-time tips for Russian-speaking players.

## Priority Features
- Rune timers (including Tormentor)
- Stack timers
- Vision and ward tracking
- Rotation advice
- Smoke purchase notifications
- Support-focused tips (no TP / TP on cooldown)
- Core farming timing suggestions

## Technical Stack
- Overwolf (or custom overlay)
- Official Valve Game State Integration (GSI)
- Claude Code for development

## Guidelines for Claude
- Prefer practical, short, actionable advice.
- Focus on "what to do right now" rather than long explanations.
- Keep the overlay minimal and non-intrusive.
- Prioritize support player workflows.
- Write code and comments in a clear style suitable for a real-time overlay.
